# 行军与战斗结算

- **状态：** 待撰写
- **对应功能：** 出兵、到达、一次性战斗、战报
- **实现顺序：** 第 5 步（先打 NPC 据点）

## 待覆盖内容

- 行军：出发格、目标格、部队组成、速度、`ArriveAt`
- 战斗：兵力、兵种克制、城防、科技、随机种子 → 战报
- 明确不做帧同步、不做客户端预测
- 战报字段、回放是否需要（第一版建议只出结果战报）
- 主要 API：`POST` 出征、查询行军、查询战报
- 到点由 Hangfire 结算，再 SignalR 推 `MarchArrived`

## 草案要点

下指令用 HTTP；等结果用推送。NPC 与玩家走同一套 `March / Battle` 结算，只是目标类型不同。
