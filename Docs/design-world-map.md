# 大地图与 NPC 据点

- **状态：** 撰写中（**格子规则已定稿**；据点、视野、画布未定）
- **对应功能：** 逻辑格子、据点、前端按视野加载
- **实现顺序：** 格子规则与 [建城](design-account-city.md) 同期；据点与视野在第 5 / 8 步

## 已定稿：格子规则（第 1 步）

地图是 **坐标索引**，不是 RTS 地形。只持久化有内容的格子；空地不存行。

| 项 | 约定 |
|----|------|
| 规模 | 200 × 200（配置 `WorldMap:Width` / `Height`，默认 200） |
| 坐标 | 整数；`x ∈ [0, Width)`，`y ∈ [0, Height)`；含 `(0,0)` |
| 占格 | 一座主城占 **1 格** |
| 占用存储 | 第 1 步以 `sg_city (x, y)` 唯一索引为准；第 5 步 NPC 据点接入时再抽「统一占用表」 |
| 选址 | 客户端不传坐标。在 `[0,W) × [0,H)` 均匀随机取格，占用则重抽，最多 `WorldMap:PlacementMaxAttempts` 次（默认 64）。仍撞车或插库唯一冲突则换格再试有限次，最终失败 `40905` |
| 距离 | 第一版 **不** 做与邻城最小间距 |
| 行军距离 | 第 5 步用曼哈顿或欧氏格数 / 速度算 `ArriveAt`（本步不定公式） |

不做：全图实时视野、每帧同步、用 DOM 铺全部格子。
