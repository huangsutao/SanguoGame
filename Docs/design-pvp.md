# 玩家对战与掠夺

- **状态：** 已定稿（第 6 步）
- **对应功能：** 对其他玩家城出兵、掠夺、保护 CD
- **实现顺序：** 第 6 步（见 [路线图](design-roadmap.md)）

复用第 5 步 [行军战斗](design-march-battle.md) 管线，`targetType = city`。城防数值见 [城墙](design-city-wall.md)。田上存量见 [城外资源](design-outer-resources.md)。

## 范围

| 做 | 不做 |
|----|------|
| 对其他玩家主城出征，到点用同一套战斗公式 | 实时国战、联盟宣战 |
| 攻方胜则可掠田上存量与仓库 | 另一套战斗公式 |
| 守方战败或被掠后进入保护 | 新手期、同联盟免战（第一版无联盟） |
| 守方 `CityAttacked`，攻方 `MarchArrived` | 多部队同时结算并行改库存 |

## 可攻击条件

出征时与结算时都要满足：

| 条件 | 失败 |
|------|------|
| 目标是其他角色的主城 | `40400` 或不存在 |
| 不是自己的城 | `40914` |
| 目标 `protectionUntil` 为空或已过期 | `40912` 保护期内 |
| 攻方带至少 1 兵 | `40910` |

第一版 **无宣战**。保护期内的城不能作为目标；被保护的玩家 **仍可以主动出征**。

结算时若目标已进入保护（行军途中被别人先打并触发保护），本次攻击 **无效**：不战斗、不掠夺、攻方兵力原数返回，战报 `summary` 写明「目标已进入保护」，`attackerWon = false`。

## 掠夺

仅 **攻方战胜** 时掠夺。顺序：先田上 `pending`，再仓库。每种资源分别计算。

1. **田上：** 每座已建成田 `takeField = floor(pending * 0.5)`，按收取公式把剩余留在田上（倒推 `lastCollectedAt`）。
2. **仓库：** 每种 `takeStore = min(floor(库存 * 0.3), 2000)`。
3. 攻方入库受自己 `resourceCap` 截断；装不下的部分 **留在守方**（田或仓），不消失。
4. 守方仓库对应扣减实际被抢走的量。

战败不掠夺。陷阱只影响伤亡，不影响掠夺比例。

## 保护 CD

守方在结算中 **战败**（含被掠）后：

```
protectionUntil = now + ProtectionSeconds     # 默认 7200
```

保护期内拒绝新的以该城为目标的出征。已在路上的部队到达后按上一节「途中进入保护」处理。

攻方不受保护（打赢别人不会给自己套免战）。

## 并发

同一座城同时被多支部队攻击时，按 **守方 `cityId` 串行** 结算（行锁）。两座城都要锁时，**先锁 Id 较小的城**，避免死锁。

资源与兵力不会少扣或多扣。城外田被掠后，第 3 步收取公式仍成立。

## SignalR `CityAttacked`

推到守方组 `city:{defenderCityId}`。payload 信封，`data` 与战报相同（便于守方刷新兵力 / 资源 / 保护）。

攻方仍收 `MarchArrived`（同一战报）。

## HTTP

沿用第 5 步：

```http
POST /api/army/march
{ "targetType": "city", "targetId": 2, "infantry": 30, "archer": 0, "cavalry": 0 }
```

`GET /api/army` 的 `protectionUntil` 供界面展示免战剩余。`GET /api/world` 对受保护的城带 `protected: true`（不暴露具体到期时刻给敌人亦可；第一版可返回布尔）。

## 本步不做

联盟、宣战、新手保护、实时国战、攻占他人主城（第一版只掠夺，不占城、不灭号）。
